# Dota 2 Analyser

Браузерное приложение, которое разбирает твои матчи в Dota 2 и превращает их в понятный план обучения.

Загрузи игру по ID (или JSON с парсом) — получишь оценку по шести осям, карту решений, автоматический коучинг и персональный план тренировки. Без регистрации, без бэкенда: всё считается в браузере.

## Возможности

- **Оценка по 6 осям** — фарм, урон, выживаемость, видение, драки и объективы. Сравнение идёт с ориентирами для конкретной роли (P1–P5), а не «в среднем по больнице».
- **Авто-коуч** — находит конкретные ошибки: ранние смерти, пропущенные драки, поздний BKB, пустой вижн, малое давление на объекты. Для каждой ошибки есть объяснение, что делать, и связанный урок.
- **Разбор по вкладкам** — обзор матча, таблица игроков, таймлайн преимущества и драк, карта с тепловой картой фарма/вардов/смертей.
- **Академия** — 20 коротких уроков на русском с практикой. Прогресс сохраняется локально.
- **Личный прогресс** — история сохранённых разборов, средние оценки по зонам, динамика и рекомендации уроков по слабым местам.
- **Демо-матчи** — два реальных матча с полным парсом. Работают офлайн, без ключей и запросов.
- **Импорт JSON** — ответ OpenDota, сырой JSON Valve или файлы `_parsed.json`. Файлы не загружаются на сервер.
- **Три источника данных**: официальный **Valve / Steam Web API** (обычно доступен из России, ключ бесплатный), **OpenDota** (полный парс) и **свой прокси** (OpenDota-совместимое зеркало). Источник переключается в настройках.

## Источники данных и доступ из России

OpenDota может не открываться из РФ. Поэтому по умолчанию приложение использует официальный API Valve.

| Источник | Что даёт | Ограничения |
| --- | --- | --- |
| **Valve · Steam Web API** | Базовая статистика матча: KDA, GPM/XPM, добивания, урон, предметы, пики | Нет парса: без таймлайнов, вардов и драк |
| **OpenDota** | Полный разбор с парсом реплея | Может быть недоступна из РФ, лимиты запросов |
| **Свой прокси** | OpenDota-совместимый API по твоему адресу | Нужен рабочий адрес |

### Как включить Valve API

1. Получи бесплатный ключ: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey). В поле **Domain** впиши `localhost` — Valve это поле не проверяет, собственный домен для ключа не нужен. Аккаунт Steam должен быть без ограничений: снимается любой покупкой от $5 (пополнение кошелька тоже считается).
2. Открой **Настройки → Откуда брать матчи → Valve** и вставь ключ.
3. Ищи свои матчи по SteamID64 / account_id или короткому имени профиля.

**Куда уходит ключ.** Ключ покидает браузер: это необходимо, чтобы API вообще ответил. Он отправляется в `api.steampowered.com` — а если ты указал прокси, то сначала в прокси. Поэтому:

* используй только свой прокси (свой Cloudflare Worker) — владелец чужого воркера видит и ключ, и твои запросы;
* не вставляй секреты прямо в URL прокси: всё, что написано в адресе, уходит посреднику;
* ключ хранится в браузере (`localStorage` по умолчанию). В настройках можно переключить хранение на `sessionStorage` — тогда ключ удаляется при закрытии вкладки.

### Если браузер блокирует Steam (CORS)

`api.steampowered.com` не отдаёт CORS-заголовки. В dev-режиме (`npm run dev`) приложение ходит через прокси Vite — ничего настраивать не нужно.

Для статичной сборки (`dist/`) есть два пути:

* указать свой прокси в **Настройках → Прокси для Steam API**. Готовый Cloudflare Worker лежит в [`tools/steam-proxy-worker.js`](tools/steam-proxy-worker.js): создай воркер в панели Cloudflare, вставь код, вставь его URL в настройки;
* или просто загрузить JSON матча на главной — разбор работает полностью офлайн.

### Парс для матчей Valve

Valve не отдаёт парс реплея. Если матч загружен через Valve, на странице матча есть кнопка **«Догрузить парс»**: загрузи `_parsed.json` (например, с другого устройства, где OpenDota доступна), и появятся таймлайны, карта, варды и драки. Обе части склеиваются по `match_id` и слоту игрока.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173 — Steam API идёт через прокси Vite
```

```bash
npm run build      # typecheck + production-сборка в dist/
npm run preview    # локальный просмотр сборки
npm run typecheck  # только проверка типов
npm run test       # юнит-тесты (vitest)
npm run check:worker   # самопроверка Cloudflare Worker (без сети)
npm run data       # пересобрать справочники и демо-данные
```

Приложение статическое: `dist/` можно выложить на любой хостинг. Для загрузки по ID нужен доступ браузера к выбранному API (Valve или OpenDota); демо-матчи и импорт JSON работают и без сети.

## Как это работает

1. **Нормализация.** Входом может быть ответ `/api/matches/:id`, файл парса, массив файлов или демо-пакет. `src/lib/normalize.ts` склеивает источники по `match_id` и `player_slot`, восстанавливает недостающие поля (нетворс, длительность, преимущество по золоту) и отмечает неполные данные.
2. **Анализ.** `src/lib/analyze.ts` определяет роль и линию, считает метрики (GPM-окна, добивания на 10/20 минуте, участие в драках, варды, байбеки, урон по строениям), оценивает каждую ось и сводит их с весами роли.
3. **Коучинг.** `src/lib/insights.ts` — набор правил: сравнивает метрики с целями роли, добавляет объяснение, упражнение и ссылки на уроки. Слабые зоны автоматически попадают в план на 3 игры.
4. **Хранение.** Настройки, история разборов, прогресс уроков и план задач лежат в `localStorage` (ключи — по желанию в `sessionStorage`). Загруженные матчи кэшируются в сессии вместе с исходными JSON, поэтому догрузка парса и обновление не требуют сети. Демо-матчи лежат в отдельных чанках и подгружаются по требованию.

Подробности по исправлениям аудита — в [AUDIT.md](AUDIT.md). Повторяемая диагностика: `node tools/audit-checks.cjs`.

## Данные

- Справочники героев и предметов — [odota/dotaconstants](https://github.com/odota/dotaconstants) (MIT).
- Демо-матчи `7490235544` и `1781962623` — публичные данные из [odota/core](https://github.com/odota/core) (OpenDota, MIT).
- API — [OpenDota](https://www.opendota.com/) и официальный [Valve / Steam Web API](https://steamcommunity.com/dev/apikey). Проект не аффилирован с Valve; Dota 2 — торговая марка Valve Corporation.

Повторная сборка данных: `tools/build-data.py` скачивает архивы `dotaconstants` и `odota/core`, оставляет только нужные поля и записывает `src/data/constants.json` и `src/data/demo/*.json`.

## Ограничения

- Без парса реплея недоступны таймлайны, варды, драки и точная карта — приложение честно предупреждает об этом и снижает детализацию. Источник Valve всегда отдаёт данные без парса.
- В данных Valve нет разбивки по линиям, поэтому позиции определяются по объёму фарма — приложение показывает это в предупреждениях.
- Тепловая карта и позиции строятся по данным OpenDota (сетка 64–192), это приблизительная визуализация, а не точный трекер передвижений.
- Оценки — эвристика на основе публичных метрик, а не «истина в последней инстанции». Используй их как повод посмотреть повтор и подумать.
- OpenDota имеет лимиты запросов; для регулярного использования добавь бесплатный API-ключ в настройках.
- Живые ответы Valve и OpenDota не проверялись в этой среде (нет исходящей сети): контракты покрыты тестами на зафиксированных фикстурах (`tests/api-contract.test.ts`).
