# Dota 2 Analyser

Браузерное приложение, которое разбирает твои матчи в Dota 2 и превращает их в понятный план обучения.

Загрузи игру по ID (или JSON с парсом) — получишь оценку по шести осям, карту решений, автоматический коучинг и персональный план тренировки. Без регистрации, без бэкенда: всё считается в браузере.

## Возможности

- **Оценка по 6 осям** — фарм, урон, выживаемость, видение, драки и объективы. Сравнение идёт с ориентирами для конкретной роли (P1–P5), а не «в среднем по больнице».
- **Авто-коуч** — находит конкретные ошибки: ранние смерти, пропущенные драки, поздний BKB, пустой вижн, малое давление на объекты. Для каждой ошибки есть объяснение, что делать, и связанный урок.
- **Разбор по вкладкам** — обзор матча, таблица игроков, таймлайн преимущества и драк, карта с тепловой картой фарма/вардов/смертей.
- **Академия** — 20 коротких уроков на русском с практикой. Прогресс сохраняется локально.
- **Личный прогресс** — история сохранённых разборов, средние оценки по зонам, динамика и рекомендации уроков по слабым местам.
- **Демо-матчи** — два реальных матча с полным парсом. Работают офлайн, без ключей и запросов.
- **Импорт JSON** — ответ OpenDota или файлы `_api.json` / `_parsed.json`. Файлы не загружаются на сервер.
- **OpenDota** — загрузка матчей по ID, поиск игрока по нику, SteamID64 или account_id и последние игры, необязательный API-ключ.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm run build      # typecheck + production-сборка в dist/
npm run preview    # локальный просмотр сборки
npm run typecheck  # только проверка типов
npm run data       # пересобрать справочники и демо-данные
```

Приложение статическое: `dist/` можно выложить на любой хостинг. Для работы загрузки по ID нужен доступ браузера к `api.opendota.com` — демо-матчи работают и без сети.

## Как это работает

1. **Нормализация.** Входом может быть ответ `/api/matches/:id`, файл парса, массив файлов или демо-пакет. `src/lib/normalize.ts` склеивает источники по `match_id` и `player_slot`, восстанавливает недостающие поля (нетворс, длительность, преимущество по золоту) и отмечает неполные данные.
2. **Анализ.** `src/lib/analyze.ts` определяет роль и линию, считает метрики (GPM-окна, добивания на 10/20 минуте, участие в драках, варды, байбеки, урон по строениям), оценивает каждую ось и сводит их с весами роли.
3. **Коучинг.** `src/lib/insights.ts` — набор правил: сравнивает метрики с целями роли, добавляет объяснение, упражнение и ссылки на уроки. Слабые зоны автоматически попадают в план на 3 игры.
4. **Хранение.** Настройки, история разборов, прогресс уроков и план задач лежат в `localStorage`. Загруженные матчи кэшируются в сессии, демо-данные встроены в сборку.

## Данные

- Справочники героев и предметов — [odota/dotaconstants](https://github.com/odota/dotaconstants) (MIT).
- Демо-матчи `7490235544` и `1781962623` — публичные данные из [odota/core](https://github.com/odota/core) (OpenDota, MIT).
- API — [OpenDota](https://www.opendota.com/). Проект не аффилирован с Valve; Dota 2 — торговая марка Valve Corporation.

Повторная сборка данных: `tools/build-data.py` скачивает архивы `dotaconstants` и `odota/core`, оставляет только нужные поля и записывает `src/data/constants.json` и `src/data/demo/*.json`.

```
src/

  data/         уроки + сгенерированные справочники и демо-матчи
  lib/          нормализация, анализ, инсайты, API, хранилище, роутер

```

## Ограничения

- Без парса реплея недоступны таймлайны, варды, драки и точная карта — приложение честно предупреждает об этом и снижает детализацию.
- Тепловая карта и позиции строятся по данным OpenDota (сетка 64–192), это приблизительная визуализация, а не точный трекер передвижений.
- Оценки — эвристика на основе публичных метрик, а не «истина в последней инстанции». Используй их как повод посмотреть повтор и подумать.
- OpenDota имеет лимиты запросов; для регулярного использования добавь бесплатный API-ключ в настройках.
